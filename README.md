## Project Overview
BaDingDong is a comprehensive attendance management system developed for academic institutions. It provides an efficient and user-friendly solution to manage attendance, appeals, and analytics. The application supports multiple user roles, including Admin, Lecturer, and Student, each with specific responsibilities and access levels.

## Technology Stack
- **Frontend**: Next.js (React Framework with server-side rendering)
- **Backend**: Next.js API Routes
- **Database**: MongoDB
- **Authentication**: NextAuth.js
- **Styling**: TailwindCSS
- **Programming Languages**: TypeScript, JavaScript

## Getting Started
### Prerequisites
Before you begin, ensure you have the following installed on your system:
1. **Node.js** - Version 18 or later
   - Download: [Node.js](https://nodejs.org/)
   - Verify installation: `node -v`
2. **Git** (Optional)
   - Download: [Git](https://git-scm.com/downloads)
   - Verify installation: `git --version`
3. **MongoDB** - Latest Version
   - Download: [MongoDB Community Server](https://www.mongodb.com/try/download/community)

### Installation and Usage
1. **Download project files:**
   - **Option 1: Clone the repository (if you have Git installed)**:
     ```bash
     git clone https://github.com/oferElz/BadingDong.git
     ```
   - **Option 2: Download as a ZIP file**:
     Download the project as a ZIP file from the GitHub repository and extract it.

2. **Set up the database**:
   - Use the provided environment variable `MONGODB_URI` for connection configuration.

3. **Install dependencies**:
   Navigate to the project directory and run:
   ```bash
   npm install
   
4. ## Run the Application:
### Development Mode:
```bash
npm run dev
Access the app at http://localhost:3000.
```
